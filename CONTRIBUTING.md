# Contributing to Structify AI

Thank you for your interest in contributing to Structify AI!

We welcome contributions that improve the project, fix bugs, enhance documentation, or introduce new features.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone <repository-url>
```

3. Create a virtual environment.

```bash
python -m venv .venv
```

4. Activate the environment.

**Windows**

```bash
.venv\Scripts\activate
```

**Linux/macOS**

```bash
source .venv/bin/activate
```

5. Install dependencies.

```bash
pip install -r requirements.txt
```

---

## Development Workflow

1. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

2. Make your changes.

3. Test the application.

```bash
streamlit run app.py
```

4. Run the test suite.

```bash
pytest
```

5. Commit your changes.

```bash
git commit -m "Add meaningful commit message"
```

6. Push your branch.

```bash
git push origin feature/your-feature-name
```

7. Open a Merge Request.

---

## Coding Guidelines

* Follow PEP 8 coding standards.
* Write clear and readable code.
* Add comments where necessary.
* Keep functions modular and reusable.
* Ensure new features do not break existing functionality.

---

## Reporting Issues

When reporting an issue, please include:

* Operating System
* Python version
* Steps to reproduce
* Expected behavior
* Actual behavior
* Screenshots (if applicable)

---

## Pull Request Guidelines

Before submitting a Merge Request:

* Ensure the project builds successfully.
* Run all tests.
* Update documentation if required.
* Keep pull requests focused on a single feature or bug fix.

---

## Code of Conduct

Please be respectful and constructive in all discussions and contributions.
